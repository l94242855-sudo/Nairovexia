CASE STUDY 01 / FINTECH

Mwanachama SACCO PWA Architecture

Production Live

The Engineering Challenge

Chamas and SACCOs in Kenya frequently operate in rural areas or venues with unstable mobile data. Members contribute via M-Pesa, but manual ledger entry leads to missing records, disputes, and delayed loan processing.

Our Solution

We built an offline-first Progressive Web App utilizing local SQLite/IndexedDB storage. The app features an intelligent SMS parser that extracts M-Pesa transaction codes and timestamps directly from notification streams, matching them against member ledgers instantly without requiring internet access.

// Architecture Pipeline Stack

Frontend:

React / Tailwind / Service Workers (PWA)

Local Storage & Sync:

SQLite (WASM) + IndexedDB + Conflict-Free Sync

Fintech Processing:

M-Pesa SMS Regex Parser + Daraja API C2B

Hosting & Delivery:

Vercel Edge Network (mwanachamaapp.vercel.app)
